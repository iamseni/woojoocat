# WoojooCat Frontend

이 프로젝트는 Vite + React 기반입니다.

## 실행 명령

프로젝트 디렉터리에서 아래 명령을 사용할 수 있습니다.

### `npm start`

Vite 개발 서버를 실행합니다. 기본 설정은 `http://localhost:3000`입니다.

### `npm run build`

TypeScript를 먼저 검사한 뒤 프로덕션 번들을 생성합니다.

### `npm run preview`

빌드 결과물을 로컬에서 미리 봅니다.

### `npm test`

Jest 테스트를 실행합니다.
